`artifacts/waymax/_archive/repeatability-relocated-20261107.json`：

归档后的旧完整运行未作为新的重载入口实测；其命令和源码中仍有历史路径。
需要日常重新评测时，优先使用未移动的主要 all 目录。

## 后续保留规则

1. 每个阶段保留一份主要结果，明确是哪次运行，不自动依赖文件修改时间。
2. 单变量实验、重复性对照和学习日志正在引用的证据单独保留或归档。
3. 代表性失败保留到归档，不静默删去失败或用成功输出覆盖。
4. 新结果通过对应阶段验证后，再更新导航；不把半成品 RUNNING 设成主要结果。
5. 归档只移动明确选择的对象，先检查目标不存在，再核对内容哈希。
6. 不自动删除、不递归清理未知目录、不改原始数据或虚拟环境。

本次整理不修改课程完成状态，未启动 GPU 或训练。
本规则与学习记录随本次学习检查点提交；原始结果继续被 git 忽略、仅保存在本机。
本次提交不包含推送远端。
