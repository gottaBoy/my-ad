## 状态规则

- `NOT_STARTED`：当天尚未学习/执行。
- `IN_PROGRESS`：已经开始，尚未满足当天门槛。
- `VERIFIED`：当天要求的阅读解释、操作与证据均已检查。
- `REVIEW_REQUIRED`：存在需要定位的失败或未知项，不能继续升级结论。

预期负测中，实验可以 `FAIL_EXPECTED`，同时学习任务为 `VERIFIED`；
两种状态必须在每日记录中分开写。
