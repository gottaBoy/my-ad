# Week 11：作品集和技术说明

## 状态

- 学习状态：`NOT_STARTED`
- 实验状态：`NOT_RUN`

## 目标

把代码整理成招聘方 10 分钟内能运行和理解的项目。

## README 结构

```text
1. 问题和范围
2. 系统结构图
3. 输入与单位
4. 构建命令
5. 测试命令
6. 示例输出
7. 指标定义
8. 成功案例
9. 失败案例
10. 已知限制
11. 下一步
```

## 必须提交

- C++ 源码；
- Python 评测脚本；
- CMake；
- 单元测试；
- 小型 fixture；
- 配置；
- 运行摘要；
- 失败分析；
- 复现命令。

不要提交：

- 大 TFRecord；
- 私有数据；
- 虚拟环境；
- 大 checkpoint；
- 仅有截图而没有命令的结果。

## 验收

删除本地 build 后，按 README 从零构建。
让一个不看聊天记录的人仅凭 README 找到输入、命令、结果和限制。
