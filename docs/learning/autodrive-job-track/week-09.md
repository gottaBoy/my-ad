# Week 09：性能、调试和可维护性

## 状态

- 学习状态：`NOT_STARTED`
- 实验状态：`NOT_RUN`

## 目标

能用数据回答：

```text
处理了多少输入？
平均延迟多少？
P95 延迟多少？
内存峰值多少？
哪个阶段最慢？
```

## 练习

给 controller 和 replay 管线增加：

- 总行数；
- 成功/拒绝计数；
- wall-clock elapsed；
- 平均/P95 延迟；
- 输入输出 hash；
- 结构化 JSON 日志。

用 Debug 和 Release 各运行一次。报告必须包含：

```text
机器/编译器
输入规模
构建类型
测量方法
结果
限制
```

## 调试练习

制造并定位：

- NaN；
- 空输入；
- 时间戳倒退；
- 越界数组；
- 负速度。

优先用测试复现，再用 gdb 或 sanitizer 定位。

## 验收

不能只写“更快”。必须有可复核的数字和命令。
