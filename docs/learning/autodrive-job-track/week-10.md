# Week 10：故障边界、降级和负向测试

## 状态

- 学习状态：`NOT_STARTED`
- 实验状态：`NOT_RUN`

## 目标

把非法状态当成一等输入：

```text
非法输入 -> 拒绝并说明原因
轨迹不可行 -> 明确失败
动作超限 -> 限幅并记录
时间戳倒退 -> 停止或降级
无有效指标 -> 不虚报 0
```

## 练习

为 planner/controller 增加：

- `ErrorCode` 枚举；
- `Result<T, ErrorCode>` 或等价接口；
- 结构化错误；
- 降级策略；
- 负测 fixture；
- 不修改原始输入的临时副本流程。

## 必须测试

1. 缺列；
2. 非有限数；
3. timestep 倒退；
4. 超大动作；
5. 空轨迹；
6. checkpoint hash 不匹配。

## 验收

每个失败都有：

```text
错误类型
触发输入
退出码或异常
用户可读信息
是否允许继续
```

“程序没有崩溃”不能写成“车辆安全”。
